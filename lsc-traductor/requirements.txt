# Traductor LSC - dependencias del proyecto
# Entorno: Windows 10 (64 bits), Python 3.12.10, solo CPU (sin GPU)
# Versiones resueltas con pip el 2026-10-22; todas probadas juntas.
#
# INSTALACION (ejecutar DENTRO de la carpeta lsc-traductor, y con --no-deps):
#   py -3.12 -m venv venv
#   venv\Scripts\Activate.ps1
#   pip install --no-deps -r requirements.txt
#
# Por que --no-deps: tensorflowjs 4.22.0 declara dos dependencias que en
# Windows no se pueden instalar bien y que este proyecto no usa:
#   - tensorflow-decision-forests: no existe para Windows. Se reemplaza por un
#     paquete vacio (carpeta vendor/), solo para que `import tensorflowjs`
#     no falle.
#   - flax: arrastra orbax-checkpoint, cuyas carpetas de prueba superan el
#     limite de 260 caracteres de rutas de Windows y rompen la instalacion.
#     Solo sirve para convertir modelos de JAX; omitirla no afecta a Keras.
# Este archivo trae TODAS las demas dependencias con version exacta, asi que
# pip no necesita resolver nada. Consecuencia: `pip check` avisara de que
# tensorflowjs "requires flax, which is not installed"; es esperado.
#
# Por que Python 3.12 y no 3.14: TensorFlow 2.21 solo publica instaladores
# para Python 3.10 a 3.13.
# =============================================================================
